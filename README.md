# FitNation Promotion App

This is a cloud-based promotional campaign application built using Docker, PHP, and PostgreSQL.  
It allows users to submit a promo code and receive a discount voucher or a chance for a free training session.

## Features
- Containerized architecture (Docker)
- NGINX load balancer & frontend
- PHP backend logic with promo validation
- PostgreSQL for data storage

## Setup Instructions
1. Clone the repo
2. Run `docker-compose up --build`
3. Visit `localhost:8082` to use the app
